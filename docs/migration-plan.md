已完成工程基础与本轮上游SDK阶段；下列路线按实际进度推进，不提供“空实现成功”或假数据来冒充兼容。

1. 契约与数据映射：基于原API、事件、命令清单、Prisma及测试建立逐项迁移表；明确哪些是机器人基础能力、账号平台能力和米哈游业务。对文档缺失和历史冲突先记录实际依据。
2. 千寻适配与事件处理：本轮完成99项HTTP契约、HTTP/WS客户端、回调、消息类型、限流、会话内顺序、进程内去重和有界队列，模拟服务验证错误/断线语义；真实微信验收及业务事件处理器待后续完成。
3. 通用服务：权限、群策略、配置、通行证Provider、凭证加密与存储、别名、通知和渲染接口。不得让米哈游和通行证互相依赖私有仓储。
4. 米哈游客户端和账号管理：本轮完成179项上游命名契约、登录/绑定验证/续期SDK，保留风控与错误，不将账号管理凭证假设为游戏客户端登录票据。账号所有权、凭证加密存储、绑定页面、业务命令和真实上游验收仍待迁移；未知App DS2和历史签名冲突必须提供明确有效的签名能力。
5. 游戏计算及展示：将上游 JS 伤害、评分、队伍和别名逻辑完整移植到 Go，以真实输入快照比较结果；适配HTML模板和资源路径，验证所有图像、字体、长内容及CSP。
6. 历史数据迁移与上线：独立数据导入、幂等和加密兼容验证，接口/事件/命令回归，资源与并发压力测量，通过后再安排生产切换。旧项目与独立资料包一直保留。

每项业务需要状态、原始路径、Go实现位置、契约用例、差异和真实验收结果。编译通过、模拟服务测试和HTTP健康并不等于上游登录或真实微信交付已验证。新服务不自动连接旧账号或数据库，生产迁移/切换另行实施。
